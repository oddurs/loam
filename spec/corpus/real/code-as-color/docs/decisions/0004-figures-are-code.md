# Figures are code, not assets

**Status:** accepted

## Context

The alternative is drawing figures in Illustrator and checking in SVGs.

## Decision

The book's thesis is that colour is computable, and a figure traced from another book cannot be checked. As code, a figure is reviewable, diffable, reproducible, and wrong in ways a test can catch. It also lets the appendix of matrices be generated by the same code the figures use, so the two cannot disagree.

## Consequences

Figures take longer to make and require a programmer to change. Fine-tuning a label position is a rebuild rather than a drag.
